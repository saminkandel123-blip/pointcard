# ポイントカードアプリ (pointcard)

SwiftUI で作ったスタンプ式ポイントカードの iOS アプリです。

## 機能

- 10 個たまると特典が受け取れるスタンプカード（2 行 × 5 列）
- お客様用 QR コードの表示
- 店員モード（PIN 認証）
  - 会計金額からスタンプを付与（500 円で 1 スタンプ）
  - スタンプを 1 個ずつ付与
  - カメラでお客様の QR を読み取って付与
- 特典の利用回数の記録
- スタンプ・利用履歴のリセット

データは `@AppStorage` で端末内に保存されます。

## 動作環境

- Xcode / iOS（SwiftUI, AVFoundation, Core Image）
- QR スキャンには実機のカメラが必要です

## 補足

店員用 PIN（`1234`）はデモ用の値で、コードに直接書かれています。
